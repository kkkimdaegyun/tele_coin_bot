# Chart Teacher Bot v0.2

BTC / ETH / SOL을 자동 감시하고, 여러 시간봉의 구조·지표·패턴·과거 유사 구간을 함께 분석해 Telegram으로 설명하는 학습형 차트 도우미입니다.

> 이 프로그램은 기술적 분석 보조 도구입니다. 패턴은 확률적 후보이고 바닥 단서 점수는 확률이 아니며, 수익이나 반전을 보장하지 않습니다.

## 현재 상태

- Windows에서 터미널 없이 숨김 실행
- 로그인 시 작업 스케줄러 `ChartTeacherBot` 자동 시작
- 서버 비정상 종료 시 감독 프로세스와 작업 스케줄러가 재시작
- BTC / ETH / SOL, 1D / 4H / 1H / 15m 자동 분석
- 5분마다 감시, 중요 신호 즉시 전송, 매시간 BTC·ETH·SOL 정기 브리핑
- 정기 브리핑 이미지는 코인을 이어 붙이지 않고 BTC·ETH·SOL 각각 한 장으로 전송
- 1H·4H EMA 20/50/200 접촉 후 마감 반응 및 정배열·역배열 전환 Telegram 알림
- EMA 알림에 실제 Binance 캔들·EMA·터치 위치 PNG 차트 첨부
- EMA 20/50/200, RSI, MACD, 거래량, ATR
- Binance 시장가 매수 체결량을 이용한 마지막 확정봉·최근 5봉 `체결 매수 비중`
- 1H·4H 거래량이 20봉 평균의 1.5배 이상이면서 체결 방향이 62% 이상으로 기울면 매수세·매도세 중요 알림
- Alternative.me 공포·탐욕 지수: 현재·전일·7일 변화와 역발상 주의 문구
- 시장 구조, 지지·저항, 추세선 돌파·이탈, 리테스트
- 캔들 패턴, 더블탑·더블바텀, 헤드앤숄더, 삼각수렴·쐐기, 플래그·페넌트, 컵앤핸들 후보
- 다이버전스, 바닥 단서 점수(확률 아님), 방향 점수, 과거 유사 구간
- SQLite에 과거 봉과 신호 저장, 중복 알림 방지
- Telegram 현재가는 전송 직전 Binance 현물 시세를 조회하고 `64K`처럼 표시
- 로그 비밀값 마스킹과 크기 기반 자동 회전
- 15m 돌파·EMA20 눌림을 1H·4H 방향, 거래량, 체결매수, RSI와 함께 확인하는 진입 단계 판단
- 급등·과열 때 `추격 금지 · 눌림 대기`, 조건이 모일 때만 `1차 분할 진입 검토` 표시
- 4H 피벗 기반 엘리어트 상승·하락 파동 후보와 피보나치 1.0/1.618/2.618 확장 구간 표시
- CoinGecko 공개 데이터 기반 USDT 도미넌스, 24시간 변화, 전체 시총·거래량 변화 감시
- USDT.D 하락+전체 시총 상승은 위험선호 우호, USDT.D 상승+전체 시총 하락은 현금 대피 경계로 분리

TradingView Premium 계정에는 `Chart Teacher - Multi-Timeframe Trigger v2`가 BTCUSDT 15분 차트에 컴파일·저장되어 있습니다. 외부 고정 HTTPS 주소가 생기면 이 스크립트의 `Any alert() function call`을 Webhook에 연결합니다.

별도 시각 지표 `Chart Teacher - MTF EMA Alignment`도 BTCUSDT 차트에 적용·저장되어 있습니다.

- EMA 20 노랑, EMA 50 주황, EMA 200 파랑
- 1D / 4H / 1H / 15m 신호등: 초록 `UP` 정배열, 빨강 `DN` 역배열, 노랑 `--` 혼조
- 3개 이상 시간대가 같은 방향이면 차트 배경을 옅게 표시
- 4개 시간대가 모두 일치하는 첫 순간에 `4TF UP` / `4TF DN` 표시
- 이평선 터치 시 해당 EMA 위에 큰 점 표시
- 신호등 아래 숫자 `20` / `50` / `200`은 마지막 확정 봉이 터치한 이평선
- 터치 허용 범위 기본값은 0.05%이며 지표 설정에서 조절 가능

시간대 신호등과 터치 요약은 확정 봉 기준이라 진행 중인 봉의 움직임으로 상태가 자주 뒤집히는 것을 줄입니다.

서버는 네 시간대를 5분마다 계속 검사하지만 알림은 압축합니다. 15분봉 EMA 접촉은 차트 분석에만 사용하고 Telegram으로 따로 보내지 않습니다. 1H·4H EMA 접촉은 봉이 마감된 뒤 선 위·아래 반응이 확인됐을 때만 알리며, 같은 종목·시간대·EMA는 기본 4시간 동안 다시 보내지 않습니다. 정배열·역배열 전환도 마감된 봉으로만 확정합니다.

KST 00:00~07:00은 조용한 시간으로 정기 브리핑과 EMA 알림을 보내지 않습니다. 이 시간에도 5분 데이터 감시는 계속되며 거래량 급증과 강한 매수·매도 체결, 확정 돌파·이탈처럼 중요한 변화만 즉시 알립니다. 07:00 이후에는 매시간 BTC·ETH·SOL 이미지와 종합 설명을 보냅니다. 정시 전후 10분 안에 중요 알림 이미지가 먼저 전송된 코인은 같은 정기 이미지를 다시 보내지 않습니다.

이미지와 텍스트 상단에는 `핵심 3종`으로 1D·4H·1H RSI, EMA 정배열·역배열, 가격의 EMA20 위·아래 위치를 우선 표시합니다. RSI가 70 과매수권이나 30 과매도권에 새로 진입하거나 빠져나오면 확정봉 기준으로 별도 중요 알림을 보냅니다. 패턴 알림에는 `1D 쌍바닥`처럼 시간대를 제목에 표시하고, 패턴의 모양과 다음 확인 조건을 초보자용 한 줄로 설명합니다.

EMA 알림에는 `한줄 결론`이 포함됩니다. 터치한 선이 지지인지 이탈인지, 어느 시간봉 종가가 어디에서 마감해야 하락 지속 또는 지지 확인으로 볼 수 있는지 조건형으로 설명합니다. 1시간 정기 브리핑에도 종목별 `한줄평`이 붙습니다.

EMA 변화 알림은 실제 Binance OHLC로 그린 차트 이미지를 먼저 보낸 뒤 상세 설명을 보냅니다. 이미지에는 최근 캔들, EMA 20/50/200, 접촉한 확정봉의 위치와 기준 가격이 표시됩니다. 이미지 생성이 일시 실패해도 텍스트 알림은 계속 전송됩니다.

거래량 옆의 `체결매수`는 Binance Kline의 Taker Buy Base Asset Volume을 전체 거래량으로 나눈 값입니다. 50% 부근은 매수·매도 체결 균형, 54% 이상은 매수 체결 우위, 62% 이상은 강한 매수 체결 우위로 설명합니다. 이는 시장가 주문의 체결 방향을 보여주는 값이며 자금 유입액·고래 매집·가격 상승 확률을 뜻하지 않습니다. 자동 중요 알림은 잡음을 줄이기 위해 1H·4H 확정봉, 거래량 1.5배 이상, 매수 비중 62% 이상 또는 38% 이하일 때만 발생합니다.

접촉 위치는 빨간 큰 원과 화살표로 강조합니다. 마감된 봉이 이평선 위에서 끝났으면 `지지 반응 확인`, 아래에서 끝났으면 `저항·이탈 반응`으로 표시하고, 다음 봉에서 어떤 조건을 확인해야 하는지도 설명합니다.

모든 중요 알림과 1시간 브리핑 이미지에는 가격, 1D/4H/1H/15m 배열, 방향·신호·바닥 점수, RSI, 거래량, MACD, 지지·저항, 패턴 후보와 한줄 결론을 함께 표시합니다. 저장된 실제 과거 봉에서 찾은 유사 구간의 이후 30개 4시간봉 경로도 현재 가격을 0%로 맞춰 겹쳐 보여줍니다. 이 경로는 예측이나 목표가가 아니라 과거에 실제로 나타났던 조건부 참고 경로입니다.

판단 직후에는 `투자자가 알아야 할 점`을 자동으로 붙입니다. 현재 해석이 무효화되는 가격과 현재가 대비 거리, 장·단기 시간대 충돌, 지지·저항 근접, 거래량 부족·확대, ATR 변동성, RSI 과열을 분석해 중요한 항목만 표시합니다. 보유 수량과 평균단가를 입력하지 않은 상태에서는 원화 손익을 임의로 추정하지 않습니다.

진입 판단의 숫자는 상승 확률이나 수익률 예측이 아니라 룰 충족 점수입니다. 15m 돌파 또는 EMA20 눌림 지지에 거래량 1.2배 이상과 체결매수 54% 이상이 함께 나타나고, 1H·4H 추세가 받쳐줄 때 점수가 올라갑니다. 24시간 급등, RSI 과열, EMA20 과대 이격, 피보나치 확장 과열이 있으면 점수와 무관하게 `추격 금지 · 눌림 대기`로 차단합니다. `1차 분할 진입 검토`도 전액 진입 명령이 아니며 화면의 무효화 가격을 먼저 정한 경우에만 계획 금액의 첫 분할을 검토하는 단계입니다. BTC·ETH·SOL 동시 진입은 세 건이 아니라 하나의 고위험 묶음으로 취급합니다.

USDT 도미넌스는 `USDT 시가총액 ÷ 전체 코인 시가총액 × 100`으로 계산합니다. 공개 CoinGecko 자료를 15분 캐시로 조회해 매시간 브리핑과 이미지에 현재값·24시간 변화를 표시하고, 로컬 SQLite에 표본을 쌓아 약 1시간·4시간 뒤부터 단기 변화도 표시합니다. USDT.D 하락과 전체 시총 상승이 함께 나타나면 진입 조건에 소폭 가점만 주며 코인 과열 차단을 해제하지 않습니다. USDT.D 상승과 전체 시총 하락이 함께 나타나면 신규 진입을 보류합니다. 위험선호·현금대피 변화 알림은 기본 12시간 중복 제한을 적용합니다.

현재 자금 계획은 BTC·ETH·SOL 각각 7,000만원입니다. `1차 분할 진입 검토`에는 700만원(10%), 이후 확인 단계에는 1,050만원(15%)과 1,750만원(25%), 예비자금은 3,500만원(50%)으로 표시합니다. `추격 금지`·`관망`·`진입 준비` 상태에서는 `지금 신규진입 0원`을 우선 표시합니다. 이는 Telegram에 계획 금액을 알려주는 기능이며 거래소 주문을 자동 실행하지 않습니다. 세 종목 계획 합계는 2억1,000만원이므로 세 코인을 동시에 진입하면 하나의 큰 상관 포지션으로 취급해야 합니다.

Telegram과 트레이더 이미지의 첫 줄은 패턴명보다 진입 행동을 우선합니다. 조건 충족 시 `🟢 BTC · 1차 분할 진입 검토 · 700만원`, 과열 시 `🔴 BTC · 지금 신규진입 0원 · 추격 금지`, 준비 단계에서는 `🟡 BTC · 진입 준비 · 1차 700만원 대기` 형식으로 표시합니다. 패턴·이평선·RSI·USDT.D는 그 아래 `감지 계기`와 판단 근거로 배치합니다. 1차 진입 조건과 중요 패턴이 동시에 발생하면 1차 분할 판단이 알림 제목을 차지합니다.

엘리어트 파동은 4H의 확인된 피벗을 이용해 1파·2파 후보와 현재 확장 비율을 근사합니다. 피보나치 1.0/1.618/2.618은 다음 확인 구간 또는 과열 경계로 표시하며 목표가 보장이나 독립적인 매수 근거로 쓰지 않습니다. 파동 표기는 분석자에 따라 달라질 수 있으므로 구조 점수에도 `확률 아님`을 명시합니다.

`바닥 단서`는 확률이 아니라 룰 기반 증거 점수입니다. 0~24는 바닥 매수 판단 보류, 25~49는 초기 단서·신규 진입 보류, 50~74는 후보 형성·확인봉과 거래량 전 대기입니다. 75 이상도 자동 진입 신호가 아닙니다. 4H EMA20 회복이 필수이고, 4H 상승 구조 또는 확인된 상승 패턴과 평균 이상 거래량 또는 확인된 상승 패턴이 함께 충족될 때만 `소액 분할 진입 검토 가능`으로 표시합니다.

공포·탐욕 지수는 [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/)의 Bitcoin 중심 시장심리 자료를 매시간 조회합니다. 현재 값과 전일·7일 변화를 표시하지만 `공포에 무조건 매수`로 해석하지 않습니다. 극단적 공포는 역발상 관찰 구간일 뿐이며 가격 구조·EMA·지지·거래량 확인 전에는 진입 근거로 사용하지 않습니다. 화면과 Telegram에 데이터 출처를 함께 표시합니다.

거시환경은 FRED의 최신 영업일 자료에서 미국 10년물 금리, 명목 광의 달러지수, VIX, 나스닥을 매시간 갱신합니다. 기술적 분석과 거시환경이 서로 반대일 때도 둘 다 그대로 표시하며, 거시 점수는 환경 요약이지 가격 예측 확률이 아닙니다.

## 매일 쓰는 파일

- `START_CHART_TEACHER.bat`: 숨김 시작. 이미 실행 중이면 중복 실행하지 않음
- `STATUS_CHART_TEACHER.bat`: `RUNNING` / `STOPPED` 확인
- `RESTART_CHART_TEACHER.bat`: 안전하게 재시작
- `STOP_CHART_TEACHER.bat`: 이 프로젝트 서버만 종료
- `INSTALL_AUTOSTART.bat`: 현재 사용자 로그인 자동 시작 등록
- `UNINSTALL_AUTOSTART.bat`: 위 작업 스케줄러 등록만 삭제

PC를 껐다 켠 뒤에는 Windows에 로그인만 하면 자동 실행됩니다. 자동 시작이 안 된 경우 `START_CHART_TEACHER.bat`를 더블클릭합니다. PC가 꺼져 있거나 절전 상태인 동안에는 PC가 Webhook을 받을 수 없습니다.

## 직접 분석과 데이터 적재

```powershell
& ".\.venv\Scripts\python.exe" ".\analyze_now.py" BTCUSDT
& ".\.venv\Scripts\python.exe" ".\backfill_history.py"
& ".\.venv\Scripts\python.exe" ".\import_tradingview_data.py" "C:\경로\TradingView.csv"
```

TradingView CSV는 계정 비밀번호나 쿠키가 아니라 차트에서 내보낸 파일만 사용합니다. Binance 공개 데이터 수집에는 별도 API 키가 필요하지 않습니다.

## TradingView Webhook 연결 전 남은 일

TradingView 서버는 `127.0.0.1`에 접속할 수 없으므로 Cloudflare Tunnel의 고정 HTTPS 주소가 필요합니다. 고정 주소에는 Cloudflare에서 관리되는 도메인이 필요합니다. 주소가 준비되면 아래 형식으로 Alert를 연결합니다.

```text
https://고정호스트/webhook/<WEBHOOK_SECRET>
```

조건은 `Chart Teacher - Multi-Timeframe Trigger v2` → `Any alert() function call`, 실행은 `Once Per Bar Close`를 사용합니다. 진행 상태와 남은 검증은 `TODO.md`에 정리되어 있습니다.
